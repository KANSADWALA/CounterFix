# F9 Ambiguous request

The request had several readings and the model silently picked one.

## How counterfix finds it

Judge: lists the readings and checks whether the answer named or asked about its choice. The linter's L6 flags requests missing who, what or which.

## Fixes it tries

In this order (a [model profile](../profiles.md) can reorder them). Each one is
kept only if it passes 2 of 3 re-runs.

| Intervention | Change |
| --- | --- |
| `add_detail` | Add the missing detail (here: the first reading the judge found) |
| `state_reading` | Have the model name the reading it chose, or ask, when a request is unclear |

## When no fix verifies

- Ask the user a clarifying question
