# F6 Dropped instruction

The answer ignored an instruction: a word or sentence count, a format, a banned word, "mention the price".

## How counterfix finds it

Live, free and exact: instructions that code can check. Judge: content instructions code cannot check.

## Fixes it tries

In this order (a [model profile](../profiles.md) can reorder them). Each one is
kept only if it passes 2 of 3 re-runs.

| Intervention | Change |
| --- | --- |
| `instruction_checklist` | Repeat the missed instructions as a checklist at the end of the prompt |

## When no fix verifies

- Check the constraint in code and re-ask
- Split the prompt
