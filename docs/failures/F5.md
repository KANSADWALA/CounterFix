# F5 False-premise acceptance

The question assumed something false and the model went along with it ("Why did Einstein win three Nobel Prizes?").

## How counterfix finds it

Judge: finds a false premise in the question and checks whether the answer accepted it.

## Fixes it tries

In this order (a [model profile](../profiles.md) can reorder them). Each one is
kept only if it passes 2 of 3 re-runs.

| Intervention | Change |
| --- | --- |
| `check_premises` | Tell the model to check the question's assumptions first |

## When no fix verifies

- Remove the false premise from the question
- Use a larger model
