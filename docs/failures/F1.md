# F1 Truncation

The answer stopped because it hit `max_tokens`, including reasoning models that spend the whole budget thinking and return an empty answer.

## How counterfix finds it

Live, free: `finish_reason` of `length` / `max_tokens`; when the provider gives no stop reason, inferred from tokens used and an answer that ends mid-sentence (marked `inferred`, lower confidence).

## Fixes it tries

In this order (a [model profile](../profiles.md) can reorder them). Each one is
kept only if it passes 2 of 3 re-runs.

| Intervention | Change |
| --- | --- |
| `raise_max_tokens` | Raise max_tokens |
| `raise_max_tokens_more` | Raise max_tokens a lot (long answers, or reasoning that uses the budget) |
| `ask_shorter` | Ask for an answer short enough to fit the current max_tokens |

## When no fix verifies

- Ask for a shorter answer
- Split the task into parts
